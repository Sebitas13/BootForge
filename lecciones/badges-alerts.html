Badges y alerts

Etiquetas compactas y mensajes que el usuario puede cerrar. Úsalos para estados y feedback, no para decorar.

5 min Principiante Lección 11 de 24

Lo que vas a aprender

  • Integrar badges en títulos, botones y listas.
  • Crear alerts con el rol y el color adecuados.
  • Permitir que un alert se cierre sin perder accesibilidad.

Los badges son etiquetas pequeñas para conteos, estados o categorías. Los alerts son mensajes de mayor tamaño para confirmar, advertir o explicar algo.

Un alert debe tener un role coherente: alert para urgencia, status para información no crítica.

No uses alerts para todo

Un alert rojo para un guardado correcto entrena al usuario a ignorar el color. Reserva alert-danger para errores que requieren acción y alert-success para confirmaciones.
